# My portfolio (or not, it's up to you)

A reponsive developer portfolio forged with Tailwind CSS in the fires of VSCode.

## Features

- **Responsive Design**: You can read it on your phone, tablet, computer, even your smart fridge if you want!
- **Modern CSS**: Built with Tailwind because writing CSS from scratch is sooooo Web 1.0
- **Semantic HTML**: Screen readers actually understand what's going on here - accessibility is not optional, folks!
- **Performance Optimized**: It could certainly outrun me at least
- **Interactive Elements**: The buttons... do stuff when clicked (yeah I'm running out of ideas here huh)
